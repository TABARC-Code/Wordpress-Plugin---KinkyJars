An adults-only kink questionnaire: fill the jars, save a poster, compare with a partner. Answers stay in the visitor's browser.

== Description ==

Visitors pick a colour or a pride palette, fill 35 jars from 1 (a little) to 5 (overflowing), cross out the ones that are a firm no, and save the result as a PNG poster. They can swap a short code with a partner to see only the jars they're both into.

The plugin stores nothing about visitors and sends nothing anywhere. Names and answers stay in each visitor's own browser.

== Installation ==

1. Plugins > Add Plugin (called Add New on older WordPress) > Upload Plugin, choose kink-jars.zip, Install Now, Activate.
2. Settings > Kink Jars > Create my Kink Jars page.
3. Preview it, then press Publish it now.

The full step-by-step guide is on GitHub: https://github.com/TABARC-Code/Wordpress-Plugin---KinkyJars

== Frequently Asked Questions ==

= Is it on WordPress.org? =

No, and it won't be. It's distributed from GitHub releases.

= What does it store? =

One option (the ID of the page it made for you) and a short-lived welcome-notice flag. Both are removed when you delete the plugin. Nothing about visitors.
